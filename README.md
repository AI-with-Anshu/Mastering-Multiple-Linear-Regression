# Day 2: Mastering Multiple Linear Regression 🚀

## Project Overview
In Day 2 of my Machine Learning journey, I upgraded from Simple Linear Regression to **Multiple Linear Regression**. This model handles multiple input features to predict a single continuous output.

## Key Concepts Covered
- **Multiple Features:** Working with 2D arrays where $X = [Area, Rooms]$.
- **Matrix Representation:** Understanding how Scikit-Learn processes multi-dimensional data.
- **Visualizing Predictions:** Plotting the 'Predicted Point' on top of the 'Regression Line' to verify model accuracy.

## Environment & Requirements
To ensure a clean development environment, I used a Python Virtual Environment (`venv`).
- **Setup:** `python -m venv ml_env`
- **Installation:** `pip install -r requirements.txt`

## Results
The model successfully predicted the price for a new data point (800 sq ft, 3 rooms), aligning perfectly with the learned trend.
